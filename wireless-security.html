Wireless Security

Wireless networks extend the attack surface beyond physical boundaries. Securing enterprise Wi-Fi requires proper authentication, encryption, network segmentation, and monitoring for rogue access points and wireless attacks.

Wi-Fi Security Protocols

Protocol Security Encryption Recommendation
WEP Broken RC4 (40/104-bit) Never use
WPA Weak TKIP Avoid if possible
WPA2-Personal Adequate AES-CCMP Guest networks only
WPA2-Enterprise Good AES-CCMP + 802.1X Corporate networks
WPA3-Personal Good SAE + AES-GCMP Home/small office
WPA3-Enterprise Best 192-bit mode + 802.1X High-security environments

Enterprise Wireless Architecture

Authentication Flow:
1. Client associates with SSID
2. AP blocks all traffic except EAP
3. Client sends EAP identity
4. RADIUS validates against AD/IdP
5. Certificate validation (EAP-TLS) or credentials (PEAP)
6. RADIUS returns Accept + VLAN assignment
7. Client receives network access

EAP Methods:
  EAP-TLS: Certificate on client. Most secure. Complex deployment.
  PEAP-MSCHAPv2: Username/password + server cert. Common enterprise.
  EAP-TTLS: Tunneled authentication. Flexible inner methods.

Wireless Threats

Evil Twin

Rogue AP mimics legitimate SSID. Captures credentials when users connect. Mitigate with 802.1X and certificate validation.

Rogue Access Point

Unauthorized AP on corporate network. Creates unmonitored entry point. Detect with WIDS/WIPS.

Deauthentication Attack

Forces clients to disconnect, captures handshake for offline cracking. WPA3's SAE resists this.

KRACK Attack

Key reinstallation attack on WPA2. Patch APs and clients. WPA3 not vulnerable.

Wireless Security Best Practices

Wireless Security Guidelines

1. Use WPA2/WPA3-Enterprise: 802.1X with certificates (EAP-TLS) is gold standard. No shared passwords.

2. Segment Guest Networks: Guest SSID on isolated VLAN. No access to corporate resources.

3. Deploy WIDS/WIPS: Detect rogue APs, evil twins, and wireless attacks. Alert and contain.

4. Disable Legacy Protocols: No WEP, no WPA-TKIP. Force WPA2-AES minimum.

5. Validate Server Certificates: Prevent evil twin by validating RADIUS server cert on clients.

6. Physical Security: APs in secured locations. Disable unused ports on switches.
