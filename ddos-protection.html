DDoS Protection

Distributed Denial of Service attacks overwhelm systems with traffic from multiple sources. Modern DDoS attacks can exceed 1 Tbps, making cloud-based scrubbing services essential. Protection requires a layered approach covering volumetric, protocol, and application-layer attacks.

DDoS Protection Architecture

Amplification Attacks Explained

DNS Amplification Attack
1
Attacker Sends Spoofed Queries
Small queries with victim's IP as source
Attack Setup
# Attacker controls botnet of 10,000 machines
# Each sends DNS queries to open resolvers
# Source IP spoofed to victim's IP

Query: "ANY google.com" (60 bytes)
Source IP: 203.0.113.50 (VICTIM - spoofed!)
Destination: Open DNS resolvers worldwide

Amplification Factor: ~50x
  60 bytes query → 3,000+ bytes response
2
DNS Resolvers Respond to Victim
Massive amplified responses flood victim
Amplification Effect
Open Resolver Behavior:
  Receives: 60 byte query (spoofed source)
  Responds: 3,000+ byte response to "source"
  
Result at Victim:
  Botnet: 10,000 bots
  Queries per bot: 1,000/sec
  Query size: 60 bytes
  Response size: 3,000 bytes
  
  Outbound from bots: 600 Mbps
  Inbound to victim: 30 Gbps (50x amplification!)
  
Victim sees flood from thousands of "legitimate" DNS servers
3
Mitigation
Cloud scrubbing absorbs and filters
Defense
DDoS Protection Response:
  
1. BGP Anycast routes traffic to scrubbing centers
2. Scrubbing centers analyze:
   - Unexpected DNS response flood (victim didn't query)
   - Pattern matches amplification attack signature
   
3. Mitigation applied:
   - Drop unsolicited DNS responses
   - Rate limit UDP/53 from unknown sources
   - Absorb remaining volume (15+ Tbps capacity)
   
4. Clean traffic forwarded to origin

Mitigation time: < 10 seconds (always-on)
                  < 5 minutes (on-demand activation)

Protection Deployment Models

Model How It Works Best For
Always-On (Inline) All traffic routes through scrubbing 24/7 High-value targets, can't afford any downtime
On-Demand Traffic rerouted when attack detected (BGP/DNS) Cost-conscious, can tolerate brief initial impact
Hybrid On-prem appliance + cloud overflow Enterprises with existing infrastructure
CDN-Based CDN absorbs attacks at edge Web applications, static content

DDoS Protection Best Practices

DDoS Protection Guidelines

1. Use Cloud-Based Protection: No on-prem solution can handle 1+ Tbps attacks. Cloud scrubbing with massive capacity is essential.

2. Always-On for Critical Assets: Don't wait for detection. Route critical services through DDoS protection 24/7.

3. Layer Your Defenses: Cloud scrubbing (volumetric) + WAF (L7) + rate limiting + geo-blocking. Defense in depth.

4. Have a Runbook: Know who to call, how to activate protection, communication plan. Practice the process.

5. Protect DNS: Your DNS is a target too. Use DDoS-protected DNS providers with anycast.

6. Know Your Baseline: Understand normal traffic patterns. Makes detecting attacks faster and reduces false positives.
