SOC Operations

The Security Operations Center (SOC) is the nerve center of enterprise security—monitoring, detecting, and responding to threats 24/7. Effective SOC operations combine skilled analysts, robust processes, and integrated technology to defend against attacks.

SOC Analyst Tiers

Alert Handling Workflow

Standard Alert Triage Process
# Alert arrives in SIEM queue

1. INITIAL TRIAGE (Tier 1) - Target: 15 minutes
   ┌─────────────────────────────────────────────┐
   │ □ Review alert details                       │
   │ □ Check for known false positive patterns    │
   │ □ Verify affected asset (criticality?)       │
   │ □ Check if related alerts exist              │
   │ □ Consult runbook for alert type             │
   └─────────────────────────────────────────────┘
   
   Decision:
   → False Positive → Document, tune detection, close
   → True Positive (Low) → Execute runbook, close
   → True Positive (Med+) → Escalate to Tier 2

2. INVESTIGATION (Tier 2) - Target: 1 hour
   ┌─────────────────────────────────────────────┐
   │ □ Timeline reconstruction                    │
   │ □ Query additional data sources              │
   │ □ Identify scope (other affected systems?)   │
   │ □ Determine attack vector                    │
   │ □ Assess business impact                     │
   └─────────────────────────────────────────────┘
   
   Decision:
   → Contained incident → Execute containment, document
   → Active/complex threat → Escalate to Tier 3/IR

3. RESPONSE (Tier 3/IR) - Variable
   ┌─────────────────────────────────────────────┐
   │ □ Lead incident response                     │
   │ □ Coordinate containment                     │
   │ □ Forensic evidence preservation             │
   │ □ Eradication and recovery                   │
   │ □ Post-incident review                       │
   └─────────────────────────────────────────────┘

SOC Metrics & KPIs

Metric Description Target
MTTD Mean Time to Detect - time from attack start to detection < 24 hours
MTTR Mean Time to Respond - time from detection to containment < 4 hours
MTTA Mean Time to Acknowledge - time from alert to first action < 15 minutes
Alert Volume Number of alerts per day/week Track trend
False Positive Rate Percentage of alerts that are not real threats < 30%
Escalation Rate Percentage of alerts escalated to higher tier 10-20%
Coverage Percentage of assets with monitoring > 95%

SOC Models

In-House SOC

Fully internal team and infrastructure. Maximum control and customization. High cost—24/7 requires 8-12+ analysts minimum.

Managed SOC (MSSP)

Outsourced to security provider. 24/7 coverage without staffing burden. Less customization, shared resources.

Hybrid SOC

MSSP for Tier 1 + nights/weekends. Internal Tier 2/3 for deep expertise. Balance of cost and control.

MDR (Managed Detection & Response)

Vendor provides detection + response. Often includes EDR/XDR platform. Turnkey solution, less visibility.

SOC Best Practices

SOC Operations Guidelines

1. Reduce Alert Fatigue: Tune detections ruthlessly. 1,000 quality alerts beat 100,000 noise. Target <30% false positive rate.

2. Document Everything: Runbooks for common scenarios. Playbooks for incident types. Knowledge base for tribal knowledge.

3. Measure and Improve: Track MTTD, MTTR. Identify bottlenecks. Continuous improvement cycle.

4. Automate Tier 0: Use SOAR to auto-close known false positives. Auto-enrich alerts. Reserve humans for decisions.

5. Invest in People: Training, certifications, career paths. Burnout is real—rotate shifts, manage workload.

6. Regular Exercises: Tabletop exercises, purple team. Test processes before real incidents.
