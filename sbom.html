Software Bill of Materials (SBOM)

An SBOM is a comprehensive inventory of all components, libraries, and dependencies in software. Like a food ingredient list, SBOMs enable organizations to quickly identify vulnerable components (like Log4j) across their software portfolio.

Why SBOM Matters

Log4Shell: The SBOM Wake-Up Call

When Log4j vulnerability (CVE-2021-44228) emerged, organizations without SBOMs spent days or weeks finding affected systems. Those with SBOMs queried their inventory in minutes.

Executive Order 14028 now requires SBOMs for software sold to the US government.

SBOM Contents

CycloneDX SBOM Example
{
  "bomFormat": "CycloneDX",
  "specVersion": "1.4",
  "version": 1,
  "metadata": {
    "timestamp": "2024-12-06T10:00:00Z",
    "component": {
      "name": "my-application",
      "version": "1.0.0",
      "type": "application"
    }
  },
  "components": [
    {
      "type": "library",
      "name": "lodash",
      "version": "4.17.21",
      "purl": "pkg:npm/[email protected]",
      "licenses": [{ "license": { "id": "MIT" } }],
      "hashes": [
        { "alg": "SHA-256", "content": "abc123..." }
      ]
    },
    {
      "type": "library",
      "name": "log4j-core",
      "version": "2.14.1",  // VULNERABLE!
      "purl": "pkg:maven/org.apache.logging.log4j/[email protected]"
    }
  ],
  "vulnerabilities": [
    {
      "id": "CVE-2021-44228",
      "source": { "name": "NVD" },
      "affects": [{ "ref": "log4j-core" }],
      "ratings": [{ "severity": "critical", "score": 10.0 }]
    }
  ]
}

SBOM Best Practices

SBOM Guidelines

1. Generate in CI/CD: Create SBOM at build time. Automate, don't manually maintain.

2. Include Transitive Dependencies: Your app uses A, A uses B. B's vulnerabilities affect you.

3. Store and Version: SBOMs are artifacts. Store with releases. Query across versions.

4. Continuous Monitoring: New CVEs emerge daily. Continuously scan SBOMs against vulnerability databases.

5. Require from Vendors: Request SBOMs from software suppliers. Part of vendor risk management.

6. Use Standard Formats: SPDX or CycloneDX. Enables tooling interoperability.
