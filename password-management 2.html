Password Management

Passwords remain a critical authentication factor despite their weaknesses. Modern password management combines strong policies, enterprise password managers, and a trajectory toward passwordless authentication.

Modern Password Policy

Legacy Policy (Avoid)
  • 8 character minimum
  • Mandatory complexity rules
  • 90-day rotation required
  • No reuse of last 12 passwords

Result: Password1! → Password2! → Password3!

NIST 800-63B (Recommended)
  • 12+ character minimum (passphrases)
  • No arbitrary complexity rules
  • No periodic rotation (unless compromised)
  • Check against breached password lists

Result: correct-horse-battery-staple

Enterprise Password Managers

Feature Description Benefit
Secure Vault AES-256 encrypted password storage Central, secure credential storage
Password Generation Random, high-entropy passwords No weak or reused passwords
Auto-fill Browser extension fills credentials UX improvement, phishing resistance
Sharing Secure credential sharing in teams No passwords in email/Slack
Audit Logs Track password access Compliance, investigations
Breach Monitoring Alert if stored passwords appear in breaches Proactive credential rotation

Password Management Best Practices

Password Implementation Guidelines

1. Deploy Password Manager: Every employee. Generate unique passwords for every account.

2. Update Policy per NIST: Long passphrases, no rotation, breach checking.

3. MFA Everywhere: Password + MFA minimum. Password alone is insufficient.

4. Plan for Passwordless: Start with IT/security staff. Passkeys are the future.

5. Block Breached Passwords: Entra ID Password Protection, Have I Been Pwned integration.

6. No Shared Accounts: Every human = individual account. Use PAM for shared system accounts.
