Physical Security

Physical security protects facilities, hardware, and people from unauthorized physical access, theft, and environmental threats. In an era of sophisticated cyber attacks, physical access often provides the easiest path to compromise.

Physical Security Controls

Control Purpose Implementation
Access Control Restrict entry to authorized personnel Badges, biometrics, PINs, mantraps
Surveillance Monitor and record activity CCTV, motion sensors, 90-day retention
Environmental Protect against fire, water, temperature Suppression, leak detection, HVAC monitoring
Visitor Management Track and control non-employees Sign-in, badges, escorts, NDA
Asset Protection Prevent theft and tampering Cable locks, equipment cages, tamper seals

Physical-Cyber Convergence

Physical Access = Cyber Access

Rogue Devices: USB drops, network taps, rogue APs planted by physical intruder.

Direct Theft: Laptop theft, server removal, backup tape theft.

Social Engineering: Tailgating, impersonation, pretexting for physical access.

Solution: Integrate physical access logs with SIEM. Badge-in events correlated with login events.

Physical Security Best Practices

Physical Security Guidelines

1. Layer Your Defenses: Multiple barriers slow attackers. Each layer detected = more response time.

2. Integrate with IT Security: Physical access logs to SIEM. Badge + VPN correlation.

3. Train Employees: Tailgating awareness. Report suspicious persons. Clean desk policy.

4. Visitor Management: No unescorted visitors in secure areas. Visitor badges distinct from employee.

5. Audit Access: Regular review of who has physical access. Remove terminated employees immediately.

6. Test Defenses: Physical penetration testing. Social engineering assessments.
