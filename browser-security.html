Browser Security

The browser is the primary interface to the internet and a major attack vector. Enterprise browser security encompasses managed browser configurations, browser isolation, extension control, and protection against web-based threats.

Browser Threat Landscape

Drive-by Downloads

Malicious code executed by visiting compromised websites. Exploits browser or plugin vulnerabilities.

Malicious Extensions

Browser extensions with excessive permissions that steal data, inject ads, or crypto-mine.

Credential Theft

Phishing sites, form grabbers, and password manager attacks targeting stored credentials.

Session Hijacking

Cookie theft, session token capture via XSS or network interception.

Browser Security Policies

Chrome Enterprise Policies (GPO/Intune)
# Key Chrome Enterprise Security Policies

# EXTENSION MANAGEMENT
ExtensionInstallBlocklist: ["*"]          # Block all by default
ExtensionInstallAllowlist: ["id1", "id2"] # Whitelist approved only
ExtensionInstallForcelist: ["security-ext"] # Force install security tools

# PASSWORD MANAGER
PasswordManagerEnabled: true
PasswordLeakDetectionEnabled: true        # Alert on breached passwords

# SAFE BROWSING
SafeBrowsingEnabled: true
SafeBrowsingProtectionLevel: 2            # Enhanced protection

# DOWNLOADS
DownloadRestrictions: 1                   # Block dangerous files
SafeBrowsingForTrustedSourcesEnabled: true

# SITE ISOLATION
SitePerProcess: true                      # Isolate each site in process

# NETWORK
DnsOverHttpsMode: "automatic"             # Enable DoH
SSLVersionMin: "tls1.2"                   # Minimum TLS 1.2
HSTS: enforce                             # HTTP Strict Transport Security

# DATA PROTECTION
SyncDisabled: true                        # Disable Chrome Sync to Google
AutofillCreditCardEnabled: false          # No credit card autofill
CookiesAllowedForUrls: ["internal.company.com"]
CookiesBlockedForUrls: ["*.tracking.com"]

# PRIVACY
BlockThirdPartyCookies: true
MetricsReportingEnabled: false

Browser Isolation

Local Browser Isolation
  • Browser runs in local VM/container
  • Disposable environment
  • Resources on endpoint
  • Latency minimal

Tools: Bromium (HP), Windows Sandbox

Remote Browser Isolation (RBI)
  • Browser runs in cloud
  • Only pixels streamed to user
  • Zero local execution
  • Some latency added

Tools: Zscaler, Menlo, Cloudflare

Browser Security Best Practices

Browser Security Guidelines

1. Standardize on One Browser: Easier to manage, policy, and monitor. Chrome or Edge for enterprise.

2. Whitelist Extensions: Block all extensions by default. Only allow approved, business-needed ones.

3. Enable Safe Browsing: Enhanced protection mode catches more threats.

4. Auto-Update: Browser updates patch critical vulnerabilities. Don't let users defer.

5. Consider RBI for Risk: High-risk users (executives, finance) benefit from browser isolation.

6. Integrate with SWG: Proxy all browser traffic through Secure Web Gateway.
