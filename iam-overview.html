Identity and Access Management (IAM)

IAM ensures the right people have the right access to the right resources at the right time. In a zero trust world, identity is the new perimeter. Strong IAM is foundational to security.

┌────────────────────────────────────────────────────┐
│ • Human users (employees, contractors)            │

Identity Lifecycle

Phase Activities Security Controls
Joiner Create identity, provision access Birthright access only, manager approval
Mover Role change, department transfer Remove old access, provision new, review
Leaver Offboarding, termination Immediate access revocation, account disable

IAM Components

Identity Provider (IdP)

Source of truth for identities. Entra ID, Okta, Ping. Authenticates users, issues tokens.

Directory Services

Stores identity data. Active Directory, LDAP. User attributes, group memberships.

Privileged Access Management

Secures admin accounts. Vaulting, session recording, JIT access.

Identity Governance (IGA)

Access reviews, provisioning, compliance. SailPoint, Saviynt.

IAM Best Practices

IAM Guidelines

1. MFA Everywhere: Password-only is not acceptable. MFA for all users, all systems.

2. Least Privilege: Grant minimum access needed. Use just-in-time elevation.

3. Automate Provisioning: HR-driven provisioning. Remove human delay and error.

4. Regular Access Reviews: Quarterly reviews minimum. Managers certify their team's access.

5. Consolidate Identity: Single source of truth. Federate, don't duplicate identities.

6. Don't Forget Non-Human: Service accounts, API keys need lifecycle management too.
