Red Team Operations

Red teaming is adversary simulation that tests an organization's detection and response capabilities. Unlike penetration testing, red teams operate with specific objectives, use real-world TTPs, and evaluate the entire security program—people, process, and technology.

Red Team vs Penetration Test

Penetration Testing
  • Find vulnerabilities
  • Defined scope/systems
  • 1-2 weeks typical
  • Blue team usually aware
  • Maximize findings
  • Technical focus
Red Team
  • Achieve objectives
  • Open scope (realistic)
  • Weeks to months
  • Blue team unaware
  • Test detection/response
  • People + process + tech

Red Team Attack Chain

Cyber Kill Chain / MITRE ATT&CK
# Red Team Attack Progression

RECONNAISSANCE (TA0043)
├── OSINT: LinkedIn, GitHub, job postings
├── Technical: DNS, subdomains, certificates
└── Social: Employee names, email format

INITIAL ACCESS (TA0001)
├── Phishing: Spearphishing with malicious docs
├── Public Exploits: CVEs on internet-facing services
└── Valid Credentials: Credential stuffing, breached passwords

EXECUTION (TA0002)
├── User Execution: Macro-enabled documents
├── Command Line: PowerShell, CMD
└── Scripting: VBS, JavaScript

PERSISTENCE (TA0003)
├── Scheduled Tasks
├── Registry Run Keys
└── DLL Side-Loading

PRIVILEGE ESCALATION (TA0004)
├── Local: Unquoted service paths, kernel exploits
├── Domain: Kerberoasting, AS-REP roasting
└── Credential Access: LSASS dump, DCSync

LATERAL MOVEMENT (TA0008)
├── Pass-the-Hash/Ticket
├── Remote Services: RDP, WinRM, SMB
└── Internal Spearphishing

COLLECTION & EXFILTRATION (TA0009, TA0010)
├── Data Staging
├── Encrypted C2 channels
└── Cloud storage, DNS tunneling

OBJECTIVE ACHIEVED
└── Crown jewels accessed, objective documented

Purple Teaming

Purple Team = Red + Blue Collaboration

Process: Red team executes technique → Blue team attempts detection → Both teams analyze gaps → Improve detections → Repeat

Benefits: Immediate feedback loop, improved detection rules, validated defenses, knowledge transfer to SOC.

Tools: Atomic Red Team, MITRE Caldera, Infection Monkey for automated TTP execution.

Red Team Best Practices

Red Team Guidelines

1. Define Clear Objectives: "Access CEO email" or "exfiltrate customer data" not "find vulnerabilities."

2. Emulate Real Threats: Use TTPs relevant to your threat model. Map to MITRE ATT&CK.

3. Test Detection, Not Just Prevention: The goal is to improve blue team capabilities, not just find holes.

4. Debrief Thoroughly: Share techniques, timeline, and detection gaps. Knowledge transfer is critical.

5. Purple Team Regularly: Collaborative exercises improve defenses faster than adversarial-only.

6. Document Everything: Timestamped logs enable blue team to correlate and improve detection.
