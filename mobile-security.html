Mobile Security

Mobile devices access corporate data from anywhere, making them high-value targets. Enterprise mobility management (EMM) combines device management (MDM), application management (MAM), and mobile threat defense (MTD) to secure the mobile workforce.

Mobile Security Components

BYOD vs. Corporate-Owned

BYOD (Personal Device)
  • Employee-owned device
  • MAM-only (no device control)
  • Work profile / container
  • Selective wipe (apps only)
  • Privacy-respecting
  • Lower cost, higher adoption

Best for: Knowledge workers, flexible policies, privacy-conscious cultures

Corporate-Owned (COPE/COBO)
  • Company-owned device
  • Full MDM + MAM control
  • Full device management
  • Full remote wipe capability
  • Maximum security control
  • Higher cost, full visibility

Best for: Regulated industries, executives, high-security roles

Mobile Threat Landscape

Mobile Malware

Trojans, spyware, banking malware. Sideloaded apps, malicious app stores. More common on Android than iOS.

Phishing

SMS phishing (smishing), malicious links in email/messaging. Smaller screens make URL inspection harder.

Network Attacks

Rogue WiFi, MITM attacks, SSL stripping. Coffee shop and hotel networks are high-risk.

Device Compromise

Jailbreaking/rooting removes security controls. Stolen devices with weak passcodes. Physical access attacks.

Mobile Security Best Practices

Mobile Security Implementation Guidelines

1. Require Device Enrollment: No access to corporate data without MDM/MAM enrollment. Conditional Access enforces this.

2. Deploy MTD: Mobile threat defense catches what MDM can't—malware, phishing, network attacks. Integrate with Conditional Access.

3. Use App Protection Policies: Even without full MDM, protect data in apps. Prevents copy/paste, screenshots, saves to personal cloud.

4. Block Jailbroken Devices: Compromised devices cannot be trusted. Immediate compliance failure, access revoked.

5. Enforce Strong Authentication: MFA required for all mobile access. Biometrics + PIN for app access.

6. Plan for Device Loss: Remote wipe capability. Selective wipe for BYOD. Users must report lost devices immediately.
