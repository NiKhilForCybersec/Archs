Cloud Access Security Broker (CASB)

CASB sits between users and cloud services to enforce security policies, provide visibility into shadow IT, protect sensitive data, and detect threats across SaaS applications. It's the control point for sanctioned and unsanctioned cloud app usage.

CASB Four Pillars

Visibility

Discover all cloud apps in use (sanctioned & shadow IT). Understand who is using what, from where, and how much data is being transferred.

Key: Shadow IT discovery, app risk scoring, usage analytics

Data Security

Prevent sensitive data from leaving the organization via cloud apps. DLP policies, encryption, and access controls for data at rest and in transit.

Key: Cloud DLP, file scanning, sharing controls

Threat Protection

Detect and respond to threats in cloud apps — compromised accounts, malware in cloud storage, insider threats, and anomalous behavior.

Key: UEBA, malware scanning, compromised account detection

Compliance

Ensure cloud usage meets regulatory requirements. Audit trails, data residency controls, and compliance reporting for GDPR, HIPAA, SOX.

Key: Audit logs, compliance templates, data residency

CASB Deployment Modes

Deployment Best Practice

Most enterprises use multimode CASB: API mode for deep integration with sanctioned apps (M365, Salesforce, Box) + Proxy mode for real-time control + Log collection for shadow IT discovery. Start with API mode for your top 5 SaaS apps, then expand.

Remediation Options
Available Actions:

1. BLOCK: Add to firewall block list
   → Immediate but disruptive

2. COACH: Display warning banner to users
   → "WeTransfer is not approved. Use OneDrive instead."
   → Educates without blocking

3. RESTRICT: Allow read-only, block uploads
   → Requires proxy mode

4. MONITOR: Continue tracking, alert on sensitive data
   → Gather more intelligence

5. SANCTION: Approve app, enable API integration
   → If business need is valid

RECOMMENDATION: 
  - Block for Finance department (sensitive data)
  - Coach for Marketing (migrate to OneDrive)
  - Create IT request workflow for file sharing needs

CASB Implementation Best Practices

Success Factors

1. Start with Visibility: Deploy log collection first. Understand your shadow IT landscape before enforcing policies. You'll be surprised.

2. Prioritize Sanctioned Apps: Enable API mode for your top 5-10 sanctioned SaaS apps (M365, Salesforce, Box, etc.) for deep visibility and control.

3. Phase DLP Policies: Start with monitoring mode, review violations, tune rules, then enable blocking. Avoid blocking legitimate business workflows.

4. Educate Before Blocking: Use coaching/warning banners before hard blocks. Help users understand why and offer approved alternatives.

5. Integrate with DLP Strategy: Align CASB DLP policies with your broader DLP program. Use consistent classification labels across endpoint, email, and cloud.</
