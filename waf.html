Web Application Firewall (WAF)

A Web Application Firewall protects web applications by inspecting HTTP/HTTPS traffic and blocking malicious requests. WAFs defend against OWASP Top 10 attacks including SQL injection, XSS, and CSRF that traditional firewalls cannot detect.

Network Firewall vs. WAF

Network Firewall (Layer 3-4)
  • Operates at network/transport layer
  • Filters by IP, port, protocol
  • Cannot inspect application payload
  • Sees "allow port 443" → allows all HTTPS
  • Blind to SQL injection, XSS, etc.

Gap: Firewall allows HTTPS on 443. Attacker sends SQL injection payload over HTTPS. Firewall sees valid TCP, allows it.

Web Application Firewall (Layer 7)
  • Operates at application layer
  • Inspects HTTP headers, body, cookies
  • Understands application context
  • Detects malicious patterns in requests
  • Blocks OWASP Top 10 attacks

Benefit: WAF inspects HTTPS payload, detects ' OR '1'='1 pattern, blocks request before it reaches app.

A02: Cryptographic Failures Sensitive data in URL parameters Detect SSN/CC patterns in requests
A03: Injection ' OR '1'='1' -- SQL/NoSQL/LDAP injection signatures
A04: Insecure Design Business logic flaws Custom rules for app-specific logic
A05: Security Misconfiguration Admin panel exposed Block access to sensitive paths
A06: Vulnerable Components Log4j exploitation attempts Virtual patching for known CVEs
A07: Auth Failures Credential stuffing Rate limiting, bot detection
A08: Integrity Failures Malicious serialized objects Detect deserialization attacks
A09: Logging Failures Log injection Sanitize log-destined data

WAF Best Practices

WAF Implementation Guidelines

1. Start in Detection Mode: Deploy in log-only mode first. Understand traffic patterns and tune rules before blocking.

2. Use Core Rule Set (CRS): OWASP CRS provides solid baseline protection. Don't reinvent the wheel.

3. Tune False Positives: False positives kill WAF projects. Create targeted exceptions rather than disabling rules entirely.

4. Virtual Patching: Use WAF rules to block exploitation of known CVEs while patching is in progress.

5. Rate Limiting: Implement rate limiting for authentication endpoints, API calls, and form submissions.

6. Monitor and Alert: WAF logs are gold. Send to SIEM, create dashboards, alert on attack patterns.
