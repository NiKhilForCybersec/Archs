IoT Security

Internet of Things (IoT) and Operational Technology (OT) devices expand the attack surface with devices that often lack basic security controls. Securing IoT requires network segmentation, visibility, and specialized monitoring.

IoT Security Challenges

No Agent Support

IoT devices can't run EDR agents. Limited CPU/memory. Traditional endpoint security doesn't apply.

Default Credentials

Many devices ship with default passwords. Mirai botnet exploited this at massive scale.

No Patching

Firmware updates rare or nonexistent. Vulnerabilities remain forever. End-of-life devices common.

Insecure Protocols

Telnet, HTTP, unencrypted protocols still common. Designed for availability, not security.

KEY PRINCIPLES:
• Segment IoT from corporate network
• Further segment by device type/function
• Limit east-west traffic between IoT segments
• Monitor all IoT traffic (can't use agents)
• Restrict internet access to required only

IoT Security Controls

Control Implementation Purpose
Network Segmentation VLANs, firewalls, SDN Isolate IoT from critical systems
Device Discovery Passive network monitoring Know what's on your network
Behavioral Monitoring Network traffic analysis Detect anomalous device behavior
Credential Management Change defaults, rotate if possible Prevent default credential attacks
Firmware Updates Patch when available, replace EOL Reduce known vulnerabilities
Encryption TLS where supported, VPN tunnels Protect data in transit

IoT Security Best Practices

IoT Security Guidelines

1. Inventory Everything: Discover all IoT devices. Shadow IoT is a major risk.

2. Segment Aggressively: IoT devices should never be on the same network as critical systems.

3. Monitor Network Traffic: Since you can't install agents, network monitoring is essential.

4. Change Default Credentials: First thing after deployment. Document in PAM if possible.

5. Restrict Internet Access: Most IoT doesn't need full internet access. Whitelist required destinations.

6. Plan for EOL: Budget for replacing devices that can't be patched.
