Privileged Identity Management (PIM)

Privileged Identity Management provides just-in-time (JIT) privileged access, reducing standing privileges. Users activate roles when needed, with time-bound access, approval workflows, and comprehensive audit trails.

Standing vs Just-in-Time Privileges

Standing Privileges (Avoid)
  • Permanent admin rights
  • Always active
  • High risk if compromised
  • Difficult to audit

Risk: Compromised account = instant admin

Just-in-Time (JIT) Access
  • Request-based activation
  • Time-limited (1-8 hours)
  • Requires justification
  • Optional approval workflow

Benefit: Reduced attack window

PIM Role Settings
# Entra ID PIM - Role Configuration Example
# Role: Global Administrator

ACTIVATION SETTINGS:
┌────────────────────────────────────────────────────────┐
│ Maximum activation duration: 4 hours                  │
│ Require MFA on activation: Yes                        │
│ Require justification: Yes                            │
│ Require ticket information: Yes                       │
│ Require approval: Yes                                 │
│   Approvers: Security Team, IT Director               │
└────────────────────────────────────────────────────────┘

ASSIGNMENT SETTINGS:
┌────────────────────────────────────────────────────────┐
│ Allow permanent eligible assignment: No               │
│ Expire eligible assignments after: 90 days            │
│ Allow permanent active assignment: No                 │
│ Expire active assignments after: 8 hours              │
│ Require MFA for active assignment: Yes                │
└────────────────────────────────────────────────────────┘

NOTIFICATION SETTINGS:
┌────────────────────────────────────────────────────────┐
│ Send notifications when members are assigned: Yes     │
│ Send notifications when members activate: Yes         │
│ Notify all eligible users when activated: Yes         │
│ Additional recipients: [email protected]                │
└────────────────────────────────────────────────────────┘

# User Activation Flow:
1. User requests "Global Administrator" activation
2. Enters justification and ticket number
3. Completes MFA challenge
4. Approval request sent to approvers
5. Once approved, role active for 4 hours
6. Auto-deactivation after time limit

High-Risk Roles for PIM

Role Risk Level Recommended Settings
Global Administrator Critical Approval required, 2-hour max, MFA, ticket
Privileged Role Administrator Critical Approval required, 2-hour max, MFA
Exchange Administrator High Approval optional, 4-hour max, MFA
Security Administrator High Approval optional, 4-hour max, MFA
User Administrator Medium No approval, 8-hour max, MFA
Helpdesk Administrator Low No approval, 8-hour max, justification

PIM Best Practices

PIM Implementation Guidelines

1. Eliminate Standing Admins: Convert all permanent admin assignments to eligible. No standing Global Admins.

2. Require Approval for Critical: Global Admin, Privileged Role Admin need approval workflow.

3. Short Activation Windows: 2-4 hours for critical roles. Users can re-activate if needed.

4. Require Business Justification: Every activation should document why access is needed.

5. Alert on Activations: SOC should receive notification of all privileged role activations.

6. Regular Access Reviews: Quarterly review of who is eligible for privileged roles.
