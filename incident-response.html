Incident Response

Incident Response (IR) is the organized approach to addressing and managing security incidents. The goal is to handle incidents in a way that limits damage, reduces recovery time and costs, and prevents future occurrences. A mature IR program combines people, process, and technology.

NIST Incident Response Lifecycle

Incident Severity Classification

Severity Definition Examples Response Time Escalation
SEV-1 Critical Active breach, data exfil, business impact Ransomware active, DC compromised, mass data theft Immediate (15 min) CISO, Legal, Exec, IR Retainer
SEV-2 High Confirmed compromise, no active exfil Malware on server, credential theft, lateral movement 1 hour Security Manager, IT Director
SEV-3 Medium Suspicious activity, potential threat Phishing success (no execution), suspicious login 4 hours SOC Lead
SEV-4 Low Minor issue, policy violation Malware blocked, failed attack, policy alert 24 hours SOC Analyst

Eradication (Hours 4-24)
Remove attacker presence and close vulnerabilities
Eradication Steps
CREDENTIAL RESET:
  ✓ Reset admin-jsmith password
  ✓ Reset all Domain Admin passwords
  ✓ Reset KRBTGT password (twice, 10hr apart)
  ✓ Revoke all active sessions
  ✓ Rotate service account passwords

MALWARE REMOVAL:
  ✓ WKS-ADMIN01: Reimaged from known-good
  ✓ FILESRV01: Isolated for forensics
  ✓ FILESRV02: Isolated for forensics
  
VULNERABILITY REMEDIATION:
  ✓ Macro execution disabled org-wide
  ✓ Admin accounts removed from email
  ✓ MFA enforced for all privileged access
  ✓ EDR prevention mode enabled (was detect-only)

NETWORK HARDENING:
  ✓ SMB traffic restricted between workstations
  ✓ RDP restricted to PAM jump servers only
  ✓ Lateral movement rules deployed to all hosts

Recovery (Days 2-5)
Restore systems and validate security
Recovery Actions
DATA RECOVERY:
  FILESRV01: Restored from backup (RPO: 4 hours)
    - Backup date: 2024-01-14 22:00 UTC
    - Data loss: ~5 hours of changes
    - Validation: Checksums verified
    
  FILESRV02: Restored from backup (RPO: 4 hours)
    - Same backup window
    - Full restore completed

SYSTEM REBUILD:
  - New servers deployed with hardened images
  - EDR agents installed and verified
  - Network monitoring enhanced
  - All systems scanned before reconnection

VALIDATION:
  ✓ No C2 callbacks detected (72hr monitoring)
  ✓ No new encryption activity
  ✓ All IOCs blocklisted

  - Day 3: All file shares restored

Post-Incident (Week 2)
Lessons learned and improvement actions
Post-Incident Review
TIMELINE SUMMARY:
  Initial Access: Phishing email (T-6 hours)
  Execution: Macro → Cobalt Strike (T-6 hours)
  Privilege Escalation: Mimikatz (T-4 hours)
  Lateral Movement: PsExec to file servers (T-2 hours)
  Impact: Ransomware deployment (T+0)
  Detection: EDR alert (T+3 minutes)
  Containment: Network isolation (T+10 minutes)

WHAT WORKED:
  ✓ EDR detected ransomware immediately
  ✓ Containment playbook executed quickly
  ✓ Backups were intact and tested
  ✓ IR retainer engaged promptly

GAPS IDENTIFIED:
  ✗ EDR was in detect-only (not prevent)
  ✗ Admin accounts had email access
  ✗ No MFA on privileged accounts
  ✗ Macros enabled by default

REMEDIATION ACTIONS (30/60/90 day plan):
  30 days: EDR to prevent mode, MFA for admins
  60 days: PAM deployment, macro hardening
  90 days: Network segmentation, tabletop exercise

Common IR Playbooks

Ransomware

Immediate isolation, scope assessment, backup validation, credential reset, forensic preservation, recovery from backup.

Phishing

Email quarantine, recipient identification, credential reset if clicked, mailbox search, sender block, user notification.

Malware

Host isolation, sample collection, IOC extraction, scope hunt, remediation, system rebuild if needed.

Credential Compromise

Password reset, session revocation, MFA reset, access log review, scope of access, monitoring for reuse.

Data Breach

Scope data exposure, legal notification, regulatory assessment, evidence preservation, PR/communications, remediation.

Insider Threat

Access revocation, DLP review, legal/HR coordination, forensic imaging, interview coordination, evidence chain.

IR Best Practices

Incident Response Success Factors

1. Have a Plan Before You Need It: Documented IR plan, tested playbooks, trained team, and established communication channels.

2. Containment Before Investigation: Stop the bleeding first. You can investigate a contained threat; you can't investigate while it's spreading.

3. Preserve Evidence: Don't reimage before forensic collection. Memory dumps, disk images, and logs are critical for root cause analysis.

4. Communicate Clearly: Regular status updates to stakeholders. Define who communicates externally (legal, PR).

5. Know When to Escalate: Clear severity definitions and escalation paths. Don't let ego delay getting help.

6. Document Everything: Timestamps, actions taken, decisions made. This protects the organization and enables improvement.
