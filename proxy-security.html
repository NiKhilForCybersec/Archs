Proxy Security

Web proxies act as intermediaries between users and the internet, providing visibility, control, and security for web traffic. Modern Secure Web Gateways (SWG) combine proxying with threat protection, DLP, and cloud access security.

Proxy Types

Forward Proxy
  • Client-side, outbound traffic
  • Users → Proxy → Internet
  • URL filtering, threat protection
  • Requires client configuration
  • Can cache content

Use for: Employee web access control, visibility

Reverse Proxy
  • Server-side, inbound traffic
  • Internet → Proxy → Servers
  • Load balancing, SSL termination
  • Transparent to clients
  • Protects origin servers

Use for: Web app protection, load distribution

SSL/TLS Inspection

SSL Inspection Flow
# SSL/TLS Inspection (Decrypt and Inspect)

User → [HTTPS] → Proxy → [HTTPS] → Website

                    ┌─────────────────────────────────────┐
                    │         SSL INSPECTION              │
                    ├─────────────────────────────────────┤
                    │                                     │
User ──[TLS]──▶ Proxy (decrypts with proxy CA)           │
               │                                         │
               │  Content inspection:                    │
               │  • Malware scanning                     │
               │  • DLP policy check                     │
               │  • URL categorization                   │
               │                                         │
               └─▶ Proxy ──[TLS]──▶ Website              │
                    (new TLS session to origin)          │
                    └─────────────────────────────────────┘

Requirements:
  • Deploy proxy CA certificate to all endpoints
  • Managed via GPO, MDM, or browser policy
  • Certificate must be trusted by clients

Bypass Categories (don't decrypt):
  • Banking/financial (security, legal)
  • Healthcare (HIPAA concerns)
  • Government sites
  • Certificate-pinned applications
SSL Inspection Considerations

Privacy: Employees should be informed of monitoring. Legal review recommended.

Certificate Pinning: Some apps reject proxy certificates. Maintain bypass list.

Performance: Decryption is CPU-intensive. Size infrastructure appropriately.

Secure Web Gateway Features

Feature Description Benefit
URL Filtering Block categories (gambling, malware, adult) Policy enforcement, reduce risk
Threat Protection Malware scanning, sandboxing Block malicious downloads
DLP Inspect uploads for sensitive data Prevent data exfiltration
Application Control Control web app usage (Dropbox, etc.) Shadow IT visibility
Bandwidth Control Throttle streaming, large downloads Network performance
User Identity Policies based on user/group Granular access control

Proxy Security Best Practices

Proxy Implementation Guidelines

1. Enable SSL Inspection: Without it, 90%+ of traffic is invisible. Block what you can't inspect.

2. Maintain Bypass Lists: Banking, healthcare, cert-pinned apps. Review quarterly.

3. Integrate with Identity: Per-user policies. SAML/OIDC integration with IdP.

4. Log Everything: Full URL logging for investigations. Integrate with SIEM.

5. Consider Cloud SWG: Remote workers need protection. Cloud-delivered proxies scale with workforce.

6. Block Uncategorized: High-risk approach but effective. New malware sites are often uncategorized.
